# Behavioral Guidelines

- **Always Provide Implementation Plan:** Always present a detailed technical implementation plan (`implementation_plan.md` artifact) and obtain explicit user approval before performing any remote or production deploys.
- **Domain-Driven Module Isolation:** Sempre que uma nova funcionalidade for criada, antes de implementá-la, determine a qual domínio ela pertence e implemente-a dentro desse módulo, evitando dependências entre domínios.
